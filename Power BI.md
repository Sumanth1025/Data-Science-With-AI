It is started in the year 2014.
It is introduced by Microsoft.

Components of power bi:-
power query:-
It is used m language for cleaning like removing duplicates, replace the null values, handle the null columns and records, transform, load the data in the power bi.



Power pivot:- It creates the relationship between the table like data module, calculations, easy to understand the data and use DAX(Data Analysis Expressions).



Power view:- It is used to visualize the data, like graphs, trees, tables, filters etc..



Power desktop:- It is used like cleaning transforming, calculating, analysing the data and share the data.





Power bi service:- It is used to publish the reports to the public like users.
